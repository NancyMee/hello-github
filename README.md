# hello-github

A tiny practice project for learning the GitHub pull request workflow.

## Usage

```bash
python hello.py
```

Output:

```
Hello, NancyMee!
2 + 3 = 5
```

## Running the tests

```bash
python -m pytest
```

## Functions

| Function | Description |
| --- | --- |
| `greet(name)` | Return a friendly greeting; falls back to `"Hello, friend!"` when no name is given. |
| `add(a, b)` | Return the sum of two numbers. |
